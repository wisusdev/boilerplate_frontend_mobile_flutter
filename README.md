# Flutter Boilerplate

## Installation

```bash
git clone https://github.com/wisusdev/boilerplate_frontend_mobile_flutter.git
cd boilerplate_frontend_mobile_flutter
flutter pub get
cp .env.example .env
```

### RUN

```bash
flutter emulators
flutter emulators --launch <emulator_id>
flutter run
```
